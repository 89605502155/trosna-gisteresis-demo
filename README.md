# trosna-gisteresis-demo

Воспроизведение графиков и численных результатов статьи «Гистерезисное правило перераспределения памяти
виртуальных машин с выдержкой времени и периодом охлаждения» (А. О. Ферубко, О. Д. Казаков, журнал
«Автоматика, связь, информатика»). Само правило реализовано в библиотеке
[trosna-gisteresis](https://github.com/89605502155/trosna-gisteresis) (`pip install trosna-gisteresis`).

Ноутбук [`demo.ipynb`](demo.ipynb) самодостаточен: в нём заданы имитационная модель сервера с четырьмя
виртуальными машинами, сравниваемые правила, расчёт всех показателей и код каждого графика. Нагрузка
порождается с фиксированными зёрнами, поэтому числа совпадают со статьёй, а последний раздел ноутбука сверяет
их с напечатанными. Ноутбук сохранён с результатами выполнения, их можно посмотреть прямо на GitHub.

| В статье | Что строит ноутбук |
|---|---|
| Рис. 5 | временная диаграмма: индекс, решения, время превышения порога, флаг готовности |
| Табл. 1 | сравнение восьми правил по 30 прогонам модели |
| Рис. 6 | фрагмент прогона модели: постоянный порог и правило с взведением по времени |
| Текст раздела «Вычислительный эксперимент» | влияние выдержки `T_d` и времени взведения `T_r` |
| Текст раздела «Программная реализация» | отметки времени Unix и время обработки одной точки |

Рис. 1–4 статьи являются схемами (контур управления, граф состояний, отсчёт выдержки, алгоритм правила)
и здесь не строятся. Время обработки точки зависит от компьютера и совпадает со статьёй только по порядку величины.

## Запуск

Нужен Python 3.11 или новее (проверено на 3.12).

```bash
git clone https://github.com/89605502155/trosna-gisteresis-demo.git
cd trosna-gisteresis-demo
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook demo.ipynb
```

Полное выполнение ноутбука занимает 3–5 минут, основное время уходит на табл. 1 и на перебор `T_d`
и `T_r`. Для быстрой проверки уменьшите `RUNS` в разделе 2 (числа тогда разойдутся со статьёй).

Выполнить ноутбук без браузера:

```bash
jupyter nbconvert --to notebook --execute --inplace demo.ipynb
```
